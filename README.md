# RheumaLens ML

AI/ML pipeline for RheumaLens — an explainable AI diagnostic co-pilot for rheumatoid arthritis detection in rural healthcare environments.

---

## Project Objectives

- Rheumatoid Arthritis severity classification
- Explainable AI using Grad-CAM
- Low-bandwidth optimized inference
- Rural healthcare compatibility
- Progression tracking across patient scans

---

## Planned ML Stack

- PyTorch
- EfficientNet-B3
- Grad-CAM
- OpenCV
- NumPy
- Jupyter Notebooks
